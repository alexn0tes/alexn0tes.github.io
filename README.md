# 拾知 · Alex Notes

从个人 Hugo 博客升级的私人知识库。主应用位于 `knowledge-base/`，支持账号访问保护、独立知识库密码、Markdown 写作、搜索、笔记本、标签、收藏、回收站和备份。

## 在线使用

[打开私人知识库：拾知](https://alexnotes-private.aglowdegu32.chatgpt.site)

私人知识库部署在 Sites，访问范围仅限所有者。首次打开时先完成账号验证，再在页面中设置自己的知识库密码；密码至少 12 个字符，无需写进代码或发送到聊天中。

旧的 `alexn0tes.github.io` 地址属于 GitHub Pages 静态托管，无法运行此应用的服务端密码验证。新的私人知识库使用单独的在线入口。原 Hugo 博客的历史内容不应被当成受密码保护的数据存储。

## 日常流程

1. 创建笔记，在编辑器中填写标题、笔记本、标签和 Markdown 正文。
2. 保存后通过搜索、标签和收藏找到内容；回收站支持恢复。
3. 使用 JSON 备份导出全部笔记，使用 Markdown 导出单篇笔记。
4. 导入备份时以新增笔记方式合并，不覆盖已有内容。
5. 离开时锁定知识库。设置中可修改密码；修改密码会撤销旧会话。

笔记存放在服务端数据库，而不是公开仓库或浏览器本地存储。下载的备份包含笔记正文，应保存在自己的可信位置。这是服务端访问控制，不是端到端加密产品。

## 仓库结构

- `knowledge-base/`：新知识库的前端、服务端 API、数据库迁移和部署配置。
- `content/`、`hugo.toml`、`themes/`、`public/`：原 Hugo 博客文件。
- `.github/workflows/`：原博客发布流程，以及新知识库的验证流程。

不要把知识库密码、会话、备份文件或真实私人笔记提交到公共 GitHub 仓库。
